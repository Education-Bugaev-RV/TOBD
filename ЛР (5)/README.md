# Лабораторная работа № 5. Классификация и регрессия.

## Задание:

1. Используя датасет из первой части лабораторной работы №4 ([flame](../ЛР%20(4)/Вариант%204/flame.txt)), выполнить классификацию методом k ближайших соседей:

    1. Построить график оценки точности работы kNN для разного числа соседей, начиная от 2-х до 20.
    1. Рекомендуется для оценки точности применять кросс-валидацию.

2. Под графиками выделить обучающие и тестовые данные с указанием их классов.

3. Вывести общий результат классификации.

4. Вывести ошибку полученного результата, в т. ч. с отрисовкой на графике.

5. Выполнить предобработку датасета из корневого каталога [house-prices-advanced](./house-prices-advanced/):
    
    1. Обнаружить  и  обработать выбросы  в  значениях признаков.
    1. Обработать  пропущенные  значения.
    1. Выполнить  преобразование  категориальных  данных (при наличии), подобрав подходящие алгоритмы.
    1. К временным данным следует применить квантование

6. Выполнить отбор переменных для регрессии.

7. Используя обработанный датасет в заданиях 5 и 6, создать модель регрессии, используя заданный в варианте метод.

8. Для полученной модели вывести среднеквадратическую ошибку (RMSE).
