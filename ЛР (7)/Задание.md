# Лабораторная работа
## Применение дерева решений для задач классификации
*На основе датасета Seeds (UCI Machine Learning Repository)*

---

## 1. Цель и задачи работы

Цель работы — освоить метод дерева решений для задачи многоклассовой классификации: построить модель на реальных данных, оценить её качество и научиться интерпретировать полученные правила классификации на языке, доступном неспециалисту.

**Задачи работы:**

1. Построить дерево решений для датасета Seeds с помощью библиотеки Scikit-learn. Визуализировать дерево в графическом виде.
2. Оценить качество классификации: рассчитать общую точность и точность по каждому классу.
3. Составить письменный отчёт для заказчика, в котором описать выявленные классы и набор правил классификации на доступном языке.

---

## 2. Описание датасета Seeds

Датасет Seeds получен из UCI Machine Learning Repository и содержит измерения геометрических характеристик зёрен пшеницы трёх сортов. Данные собраны с помощью мягкого рентгеновского излучения — неразрушающего метода визуализации внутренней структуры зерна.

> **Источник:** UCI Machine Learning Repository, датасет «Seeds»  
> **URL:** https://archive.ics.uci.edu/dataset/236/seeds  
> **Расположение:** [Seed](Seed/)   

### 2.1. Объём данных

- Количество образцов: **210**
- Количество признаков: **7 числовых**
- Целевой признак (target): номер сорта пшеницы (1, 2 или 3)
- Классы сбалансированы: по **70 образцов** каждого сорта

### 2.2. Признаки датасета

*Таблица 1. Признаки датасета Seeds*

| № | Название (англ.) | Название (рус.) | Ед. изм. | Описание |
|---|-----------------|----------------|----------|----------|
| 1 | Area | Площадь | мм² | Площадь зерна пшеницы |
| 2 | Perimeter | Периметр | мм | Длина контура зерна |
| 3 | Compactness | Компактность | безразм. | Отношение площади к квадрату периметра (4π·A/P²) |
| 4 | Kernel length | Длина зерна | мм | Длина зерна по главной оси |
| 5 | Kernel width | Ширина зерна | мм | Ширина зерна по поперечной оси |
| 6 | Asymmetry coefficient | Коэффициент асимметрии | безразм. | Мера несимметричности формы зерна |
| 7 | Groove length | Длина бороздки | мм | Длина центральной бороздки зерна |

### 2.3. Классы (сорта пшеницы)

Датасет содержит три класса, соответствующие трём сортам мягкой пшеницы:

- **Класс 1 — сорт Kama:** зёрна среднего размера, округлой компактной формы.
- **Класс 2 — сорт Rosa:** наиболее крупные зёрна, с наибольшей площадью и периметром.
- **Класс 3 — сорт Canadian:** наиболее мелкие и вытянутые зёрна.

## 4. Обучение модели

### 4.1. Загрузка и подготовка данных

1. Загрузить датасет Seeds из директории [Seed](Seed/).
2. Назначить столбцам имена.
3. Проверить датасет на наличие пропущенных значений (метод `isnull().sum()`).
4. Вывести описательную статистику (метод `describe()`) для понимания диапазонов признаков.
5. Убедиться в сбалансированности классов (метод `value_counts()` для столбца `target`).

### 4.2. Разделение на обучающую и тестовую выборки

1. Разделить данные на матрицу признаков **X** (столбцы `area`…`groove_length`) и вектор целевого признака **y** (столбец `target`).
2. Разделить X и y на обучающую и тестовую выборки в пропорции **80/20** с помощью функции `train_test_split`. Для воспроизводимости установить фиксированный `random_state`.
3. Вывести размеры полученных выборок.

### 4.3. Построение дерева решений

1. Создать объект классификатора `DecisionTreeClassifier` из модуля `sklearn.tree`. Начальные гиперпараметры: `criterion='gini'`, `random_state=42`, остальные — по умолчанию.
2. Обучить классификатор на обучающей выборке (метод `fit`).
3. Получить предсказания на тестовой выборке (метод `predict`).
4. Провести эксперименты с ограничением глубины дерева: обучить модели с параметром `max_depth = 2, 3, 4, 5` и сравнить точность на тестовой выборке. Результаты свести в таблицу.

### 4.4. Визуализация дерева решений

1. Визуализировать построенное дерево с помощью функции `plot_tree` (модуль `sklearn.tree`) или `export_graphviz` с последующим рендерингом через `graphviz`.
2. При вызове функции визуализации обязательно задать параметры:
   - `feature_names` — список названий признаков на русском языке (из таблицы 1);
   - `class_names` — список `['Kama', 'Rosa', 'Canadian']`;
   - `filled=True` — для раскраски узлов по классу;
   - `rounded=True`, `fontsize=10`.
3. Сохранить изображение дерева в файл PNG с разрешением не менее 150 dpi (параметр `dpi` функции `savefig`). Имя файла: `decision_tree.png`.

### 4.5. Оценка качества модели

1. Вычислить общую точность классификации (`accuracy_score`).
3. Построить и визуализировать матрицу ошибок (`ConfusionMatrixDisplay`).

## 5. Структура письменного отчёта для заказчика

По результатам работы необходимо составить письменный отчёт в формате Markdown, адресованный заказчику — специалисту в предметной области, не имеющему подготовки в области машинного обучения. Отчёт должен содержать следующие разделы.

### 5.1. Описание применяемого датасета

В разделе необходимо указать:

- Общий объём данных (количество образцов и признаков).
- Таблицу с перечнем всех признаков: название на русском языке, единица измерения, краткое пояснение физического смысла.
- Описание трёх сортов пшеницы как объектов классификации (на каком объёме данных строилась модель, какой объём использовался для проверки).

### 5.2. Общий результат классификации

В разделе необходимо ответить на вопросы:

- Позволяет ли построенное дерево решений провести однозначную классификацию всех образцов тестовой выборки?
- Если нет — какой общий процент образцов распознаётся верно?
- Каков процент верно распознанных образцов отдельно по каждому из трёх сортов?
- Какие сорта путаются между собой чаще всего (анализ матрицы ошибок)?

Результаты представить в виде таблицы и прокомментировать. Избегать профессионального жаргона: вместо «accuracy» писать «доля верно определённых образцов», вместо «recall» — «полнота», «доля найденных экземпляров данного сорта».

### 5.3. Набор правил классификации

Для каждого из трёх сортов необходимо составить набор правил в формате «Если … то зерно относится к сорту …». Правила извлекаются из построенного дерева решений: каждый путь от корня до листа с преобладающим классом преобразуется в логическое условие.

**Требования к правилам:**

- Все пороговые значения округлить до двух знаков после запятой.
- Названия признаков использовать на русском языке (из таблицы 1).
- Правило должно быть понятно агроному или технологу без специальной подготовки.
- Привести не менее двух правил для каждого класса (если дерево их содержит).

**Пример оформления правила:**

> **Правило №1 — Сорт Rosa:**  
> $$
> \begin{cases}
> \text{Длина бороздки} > 5,88 мм \\
> \text{Площадь зерна} > 15,53 мм^2
> \end{cases}
> \quad \Longrightarrow \quad
> \text{Сорт: } \mathbf{Rosa} \text{ (высокая вероятность)}
> $$

### 5.4. Приложение

К отчёту прикладывается файл `decision_tree.png` — графическое изображение построенного дерева решений. В документе отчёта должна быть интеграция данного изображения и явные ссылки.
