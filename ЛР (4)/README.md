# Иерархическая и вероятностная кластеризации

## Исходные данные

Исходные данные: имеется 2 датасета: один в виде наборов 
координат  в  двумерном  пространстве,  второй  имеет 
прикладной  характер  (т.е.  из  реальных  исследований, 
размещённых в Kaggle).  

[Первый датасет](Вариант%204/flame.txt) находится в корневом каталоге варианта, 
представлен набором точек x, y. Набор данных используется 
для выполнения заданий 2-4, 7. 

[Второй  датасет](Вариант%204/Seed/Seed_Data.csv)  расположен  в  папке  внутри  корневого 
каталога  варианта.  Описание  датасета  хранится  в  файле 
[Context.md](Вариант%204/Seed/Context.md).  Набор  данных  используется  для 
выполнения заданий 5-7.
